产品概述

PCT-100 化工控制实训装置专为工业物联网教学及小型自动化场景设计。基于 ESP32-C3 平台，集成光敏传感器、DS18B20 温度传感器、继电器输出（灯/风扇）、WS2812 全彩状态灯、OLED 显示屏，支持 WiFi 配网与 MQTT 远程监控，可实现自动/手动双模式控制。

ESP32-C3 工业级主控

硬件接口定义

主控及外设

  • MCU： ESP32-C3 (RISC-V)
  • 光敏电阻： GPIO1 (ADC1_CH1)
  • DS18B20： GPIO10 (OneWire)
  • 继电器-灯： GPIO6 (USB2)
  • 继电器-风扇： GPIO7 (USB3)
  • KEY1 (自锁)： GPIO20, PULLDOWN
  • KEY2 (轻触)： GPIO21, PULLDOWN

通信与显示

  • OLED (SH1106)： I2C: SDA=4, SCL=5
  • RGB LED (WS2812)： GPIO0
  • WiFi： 2.4GHz STA/AP 模式
  • MQTT Broker： 可配置 (默认 47.98.170.180:8081)
  • 供电： Type-C 5V / 2A

功能特性

自动控制

光照<225Lux开灯，温度>阈值开风扇，状态变化即时上报MQTT。

手动控制

KEY2短按循环切换灯/风扇/全开/全关，支持远程MQTT控制。

WiFi配网

开机自动连接保存WiFi，长按清除配置，支持串口与Web配网。

MQTT远程

动态修改服务器、端口、设备ID，支持远程重启、阈值设置等。

按键操作说明

按键操作方式功能描述
KEY1自锁开关 (闭合/断开)总闸控制：断开时全部断电，闭合时系统运行
KEY2短按 (<1秒)手动模式下循环切换输出状态
KEY2长按 (1~2秒)自动模式 ↔ 手动模式切换
KEY1断开+KEY2长按长按5秒清除所有WiFi配置并重启设备

所有按键动作均会触发 MQTT 状态立即上报

串口命令 (115200 baud)

命令说明
scan扫描附近WiFi网络
connect切换到WiFi模式(交互式配网)
offline切换到离线模式 (红色指示灯)
clearwifi清除Flash中的WiFi配置
reboot软重启设备
wifiinfo显示当前连接WiFi信息
setmqtt交互式设置MQTT参数
showmqtt显示当前MQTT配置
resetmqtt重置MQTT配置为出厂默认

MQTT 通信协议

Broker: 47.98.170.180:8081 (可串口修改)
协议版本: MQTT 3.1.1
设备ID: 出厂为 PCT_100_027，可自定义

WS2812 RGB 状态指示灯

常规状态

  • 绿色常亮 → WiFi已连 + 自动模式 + 正常
  • 蓝色常亮 → WiFi已连 + 手动模式
  • 黄色常亮 → WiFi已连 + KEY1断开(待机)
  • 红色常亮 → WiFi未连接 / 离线模式
  • 紫色/品红闪烁 → WiFi指示脉冲(未联网)

特殊效果

  • 白色短闪 → WiFi已连接 (每3秒指示)
  • 呼吸红 → 自动模式 + 温度过高告警
  • 开机彩虹 → 上电或首次开启总闸时演示全彩能力

WiFi指示脉冲不会干扰主状态色，每3秒短暂闪烁后恢复。

🎬 开机动画流程

  1. WS2812 万色灯闪烁（红橙黄绿青蓝紫白双循环 + 彩虹收尾）~2s
  2. OLED 进度条动画 + 设备版本显示 ~2s
  3. NTP 网络对时（若 WiFi 已连接）~2s
  4. OLED 显示 WiFi 信息页 + 彩虹灯效 ~2.5s
  5. 进入主控制界面，开始传感器采集

总动画时长约 8 秒，展示设备全功能并等待总闸开启。

✔ 所有配置（WiFi / MQTT）保存在 Flash 中，断电不丢失。
